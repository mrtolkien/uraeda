# 0002. No user accounts

The app MUST NOT have user accounts or a sign-in screen.

## Context

Accounts need a server and personal data, against the constitution's local first principle. Sync
between devices waits until this decision is revisited. Decided when the project started, before the
Uraeda workflow.
