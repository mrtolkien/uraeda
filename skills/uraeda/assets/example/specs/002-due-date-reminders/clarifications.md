## Session 2026-10-14

### Q1: How do reminders reach the user?

Why it matters: a reminder that arrives with the app closed needs a server, which the constitution
does not allow without your approval.

**Recommended:** Option A - it keeps the app local first. Users who keep the app open in a tab get
every reminder. See [research](research.md#showing-reminders).

| Option | Description                                                            |
| ------ | ---------------------------------------------------------------------- |
| A      | A notification while the app is open, and a banner listing missed ones |
| B      | A push server, so reminders arrive with the app closed                 |

**Answer:** yes

### Q2: When does a reminder fire?

Why it matters: a time per task changes how due dates are stored, which other features rely on.

**Recommended:** Option A - a time per task, 9:00 by default. Reminders are only useful at the right
time of day. See [research](research.md#reminder-time).

| Option | Description                                       |
| ------ | ------------------------------------------------- |
| A      | A time per task, 9:00 by default                  |
| B      | One time for all reminders, in the app's settings |

**Answer:** A
