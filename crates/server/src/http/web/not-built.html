This ura was built without the web app

The server runs, and the Linux app and paired devices reach it. Only the app's pages for a browser are missing from this build.

In a checkout of Uraeda, just web-build makes them in target/web. Then start the server with URAEDA_WEB_BUILD=target/web to serve that folder, or build ura with it set, as just package does, to hold them.

A released ura holds them already.
