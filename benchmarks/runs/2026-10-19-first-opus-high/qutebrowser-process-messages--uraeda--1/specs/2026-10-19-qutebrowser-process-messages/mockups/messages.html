Process messages

The messages qutebrowser shows when a process started by :spawn finishes, here with PID 1234. The spec's text is the reference: this page shows where it appears.

A failed exit (US1)

Before: Command exited with status 1. See :process for details.

page
Command exited with status 1. See :process 1234 for details.
[NORMAL] https://example.com/

A successful exit, with :spawn -v (US1)

Before: Command exited successfully.

page
Executing: true
Command exited successfully. See :process 1234 for details.
[NORMAL] https://example.com/

A crash (US2)

Before: Command crashed. See :process for details.

page
Command crashed with status 11 (SIGSEGV). See :process 1234 for details.
[NORMAL] https://example.com/

A stop with SIGTERM, without -v (US3)

Before: Command crashed. See :process for details.

page
(no message)
[NORMAL] https://example.com/

A stop with SIGTERM, with :spawn -v (US3)

Before: the same error as above.

page
Executing: sleep 100
Command terminated with status 15 (SIGTERM). See :process 1234 for details.
[NORMAL] https://example.com/
