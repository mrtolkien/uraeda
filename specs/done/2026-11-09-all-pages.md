# Record: `m` opens the model picker

>

## What and why

On the pages where the human picks what a session runs on, the New page and a session's page, `m`
opens the model picker. Before this change, only the composer's button and `Space a`, a two-key
sequence, opened it.

## Behaviour

- In a composer that picks what its session runs on, `m` opens the picker as its button does: the
  model step on the New page and before a session's first message, the effort step in a running
  session. It works on the New page, a session's page, and a feature's session in a review page's
  column, once the focus is out of the text field: in the field, `m` is typed.
- The status line hints `m model`, or `m effort` in a running session, before `i insert`. `Space a`
  still opens the same step, unhinted.
- `m` keeps its base meaning, move mode, on lists whose rows move: home, the inbox, and the
  priorities. The picker beside an answered round's "Apply the answers", on the inbox and the
  decisions, and the change's start dialog keep only the button and `Space a`, so the inbox's `m`
  still moves a note.
- With the single-key shortcuts off, `m` is off with the others, as `Space a` already was; the
  button stays.

## Design

[`SessionPicker.tsx`](/packages/web/src/SessionPicker.tsx) declares `m` beside `Space a`, with the
same label and action, when it is given `hasPageKey`.
[`ComposerPicker.tsx`](/packages/web/src/ComposerPicker.tsx) passes it to both of a composer's
pickers, a new session's and a running session's effort, so every composer has the key and the round
banners of [`StartChat.tsx`](/packages/web/src/StartChat.tsx) do not. The
[Keyboard](/specs/decisions/keyboard.md) decision forbids a key meaning two things on one page, and
the registry throws on one in development and tests: no page draws a composer beside movable rows.

- [`keys-pages.test.tsx`](/packages/web/src/__tests__/keys-pages.test.tsx): `m` on the New page and
  a session's page opens the model step, in a running session the effort step, and in a composer it
  is typed.
- [`keys-inbox.test.tsx`](/packages/web/src/__tests__/keys-inbox.test.tsx): beside an answered
  triage's picker, `m` still puts a note in move mode.
- The [keyboard guide](/specs/ui/keyboard.md) and [the web UI's documentation](/docs/web-ui.md) name
  the key.

## Gotchas

- `m` is kept off the round banners' picker: an answered inbox triage's banner holds one on the same
  page as the inbox's movable notes, and the registry refuses the second `m`
  ([`StartChat.tsx`](/packages/web/src/StartChat.tsx)).
