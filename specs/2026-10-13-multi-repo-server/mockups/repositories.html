Multi-repo server

The repository selector, adding a repository, the first run, and a missing folder, on a wide screen (desktop, 19 px text) and a narrow one (phone, 17 px text). Names and paths are examples. The spec's text is the reference for behaviour.

The heading opens the menu: the repositories, most recently opened first, the current one checked, a filter, a missing folder marked, and "Add a repository…". A popover on wide screens, a bottom sheet on narrow ones. Home stays the first row of the navigation.

3. Adding a repository

"Add a repository…" opens a short form: a dialog on wide screens, a sheet on narrow ones. The path completes as it is typed, with the folders the server finds; folders in git carry a "git" mark. Enter or "Add" adds the folder and opens it.
