# Keyboard nav in questions and specs

## What

- Reviews (spec, plan): select blocks with the keys, as a list's rows, and comment on them.
- Questions rounds: pick an option of a question with a key.

## Why

## Notes

From the desktop keyboard walkthrough of 2026-11-05 (persona Tolki, `specs/ui/personas.md`):

- Spec review: `j` scrolls; blocks are reachable only by Tab, one toggle per block, after the
  sidebar. The key map and the status line show no page key. The flows guide says a comment starts
  "by tapping what it is about … or by selecting it with the keys".
- Walkthrough's idea: `j` `k` move the selected block, `Shift`+`j`/`k` extend it, `Enter` or `c`
  comments; the status line shows "j k block · ⏎ comment". The same on the plan review.
- Questions: options are checkboxes; arrows do nothing; picking takes Tab past the title, a link,
  and each option, then `Space`.
- Walkthrough's idea: `1`–`9` pick the options of the question at the top, in the order shown,
  saving as a click does. Letters would read better, but `a` and `b` already mean add and back.
- Already done on the walkthrough's branch: a selected block's comment field takes the focus, and
  `n` goes on from the first blank question, then to Commit.
