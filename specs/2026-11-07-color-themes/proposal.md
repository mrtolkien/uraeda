# Color themes

## What

Color themes: simple toggle for color themes. Split them in light vs dark.

- The classic open source ones. Catpucin, Dracula, Tokyo night, Monokai, GitHub, …
- also add the pi agent default color theme that they just released

## Why

It’s nice to have a bit of customization

## Notes

Make it clean architecturally: all themes should be typed with clear color names (surfaces, heading
levels/hierarchy, …).

Also make it expandable: a user should be allowed to define a custom theme in the conf file.
