7. Answering a round

‹Clarifications, round 014 of 11
Q2
How does your iPhone reach the server?

The proposal says no security is needed, since you access it through Tailscale only. The active stack decision requires the server to listen on 127.0.0.1, and to reject any Host but 127.0.0.1 or localhost, and foreign origins, because the server will commit and start agents, and a web page you open could otherwise reach it. tailscale serve keeps the server on 127.0.0.1, but passes your machine's *.ts.net name, which both Vite and the server's guard reject today. Tailscale keeps other machines out, not a malicious page opened on your Mac or phone. More in discovery.

Why it matters: it amends an active decision, which every later server feature follows.

Recommended
ARun tailscale serve to the server on 127.0.0.1; the server and Vite also accept the *.ts.net host and its https:// origin given in an option. The stack decision's Host rule gains that case.
  • one command on your machine, HTTPS, and a page you browse still cannot reach the server.
  • the decision changes, and the host name is set once in an option.
  • it gives the proposal its access, and keeps what the rule protects.
BA, and requests that come through Tailscale must also carry its Tailscale-User-Login header, which tailscale serve adds and strips from incoming requests.
  • only people logged into your tailnet get in, at no cost.
  • a second check, which the proposal does not ask for.
CListen on every interface, without the guard, as the proposal says.
  • nothing to set up.
  • the stack decision's rule is removed, your local network reaches the server too, and any page you browse can.
Answer:A: and the hosts should be easy to set in a .envsaved ✓
