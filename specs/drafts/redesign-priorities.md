# Redesign home, inbox, and priorities

## What

A functional pass on the home, inbox, and priorities pages.

- Priorities line -> edit text is too many clicks (one opens the sidebar, then edit, then edit
  again...), it's bad UI for the most standard path
- Priorities that have a draft file associated should be highlighted
- Priorities -> Draft should bring its children bullet points
- When adding a priority from home screen on mobile we need to go to the priorities page manually to
  commit…
- Add a constitution view, should not be part of the sidebar but should be there _somewhere_, maybe
  in the home or a "project overview"

## Why

Inbox and priorities are the entry point of every piece of work: the most standard paths should be
the fastest.
