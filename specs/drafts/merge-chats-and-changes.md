# Merge chats and changes

## What

Merge chats and changes.

Chat = chit chat or targeted change, likely in a short iteration loop -> ~ normal claude code

Change = code change with a clearer goal and autonomy

Also if there's a `+` near changes/chats there should also be one near features...

## Why

A change it's just a chat that grew

A feature is a change that grew

It should be possible to switch between flows smoothly
