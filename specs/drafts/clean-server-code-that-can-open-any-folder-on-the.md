# Multi-repo server

## What

When running the server, the top left icon should have a repository selector.

It should be possible to add any folder of the machine as a repository in uraeda.

Uraeda's web ui should also be easy to run (maybe with npx or stg similar?)

## Why

Uraeda is perfect for managing multiple repos + when it'll be cleanly packaged there will need to be
a flow to select the first repo anyways.
