# Dedicated session view

## What

There should be a _dedicated_ session view, not just a sidebar, even on desktop.

- View the current task in the sidebar even if it's not run by our session: the checkmarks in the
  plan should cover it

## Why

Following what an agent does is one of the main things the UI is for, and the sidebar is too small
for it.
