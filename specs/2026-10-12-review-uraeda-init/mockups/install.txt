Mockups of ura install and ura init, as drawn in a terminal 100 columns wide.
"$" lines are what the user types. Pickers draw inline, under the command's output, in the
terminal's own colours: the cursor row in bold cyan, the help line dimmed. Without colour, the ">"
and "[x]" carry the same information. <N> is the number of files in the skill.

================================================================================================
1. ura install, scope picker, open (the cursor starts on "Your user")
================================================================================================

$ ura install
Install the Uraeda skill for:
> Your user, in ~/: every repository on this machine
  This repository, in uraeda/
↑/↓ move · enter confirm · esc cancel

================================================================================================

   The scope picker is replaced by its answer line.
================================================================================================

================================================================================================
5. ura install --user, run again on this machine, where ~/.claude/skills/uraeda links to a
   checkout of Uraeda, and the repository has its own copy from an older ura init
================================================================================================

$ ura install --user --agents --claude
kept    ~/.agents/skills/uraeda/: up to date
kept    ~/.claude/skills/uraeda: a link to /home/me/dev/uraeda/skills/uraeda
note    another copy in .agents/skills/uraeda: Claude Code reads the user's copy, other agents
        the repository's

================================================================================================
6. ura install --user --update, with one file edited by the human and one unedited file changed
================================================================================================

$ ura install --user --update
kept    ~/.agents/skills/uraeda/SKILL.md: edited since installed
updated ~/.agents/skills/uraeda/ (1 file)

$ ura install --user --update        # nothing ura installed in ~/
nothing to update: ura installed no skill in ~/

================================================================================================
7. ura install without a terminal, or with --no-input, and flags missing (stderr, exit 1)
================================================================================================

$ ura install --user
ura: no terminal to ask: pass --agents, --claude, or both

$ ura install --agents
ura: no terminal to ask: pass --user or --repo
