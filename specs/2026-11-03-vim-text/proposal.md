# Vim in text edit mode

## What

Vim in text edit mode.

It’s simple: I want to be able to use vim key bindings in ALL text input fields. And ideally not
just some basic emulation but ans many keys as possible. And it should be all client side and
instant.

I also don’t want to reinvent the wheel. Review feasibility and complexity, I’ll drop it if it’s too
much work.
