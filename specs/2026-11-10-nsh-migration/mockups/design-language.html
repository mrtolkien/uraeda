A surface now takes one of four heights, and everything else follows from it: its fill, its edge, its shadow, and whether it is glass. Surface is the only component that draws a shadow, so depth reads the same on every page.

The four heights

type Height = "recessed" | "standard" | "raised" | "overlay";

export function Surface(props: { height: Height; children: Node }) {
  const t = tokens.height[props.height]; // fill, edge, shadow, blur, tint, glow
  return <HeightContext value={props.height}>{draw(t, props.children)}</HeightContext>;
}

A field inside a dialog is still a well: it takes the dialog's own fill, darkened by the same step. I changed the tokens to carry one set per height.

1 · Heights · four, each a fixed recipe

Every surface picks a height, and takes its fill, edge, shadow, and glass from it. Each stage below has text behind it, to show what glass does.

recessed
a field, a code block, a diff
A darker fill, and a soft shade under its top edge.
standard
a pane, on the backdrop
The surface one reads on. Flat: no light on it, and no shadow.
raised
a card, a selected row's bar
A lighter fill, a lit top edge, and a soft shadow under it.
overlay
a menu, a dialog, a toast
Glass: a thin tint, an edge that bends what is behind it, a bright rim, a deep shadow.

Each height inside each other. Rows are the outer surface, columns the inner one.

2 · Edges and light · only the focus emits light

At rest nothing glows. The focused pane lights its edge in two colours, as a window's border on a desktop, and the edge goes round its title. "Needs you" is a colour, not a lamp. A running pane has a steady line, and moves only when its state changes.
