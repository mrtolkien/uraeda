# Keyboard nav in questions and specs

## What

- Reviews (spec, plan): select blocks with the keys, as a list's rows, and comment on them. Mouse is
  not necessary to do _any_ action.
- Questions rounds: pick an option of a question with a key.

Make sure this isn’t too complex though. Looking at mockups for example will require using the mouse
anyways. Maybe this is foolish and should be a small navigation layer.

## Why

We still need the mouse for those two pages. The existing keyboard nav is too basic and does not let
us easily comment and navigate.
