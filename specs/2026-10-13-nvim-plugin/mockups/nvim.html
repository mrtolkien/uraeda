Nvim plugin: screens

Neovim with LazyVim and snacks.picker, in the terminal's own colours. Text in these screens is the text the spec fixes; the spec wins where the two disagree.

1. The <leader>a menu in a spec (which-key)

Uraeda's keys show next to Claude Code's, only in workflow files, except "waiting".

<leader>a  +ai
  a  Accept diff                  m  Uraeda comment
  b  Add current buffer           n  Uraeda draft line
  c  Toggle Claude                p  Uraeda start feature
  C  Continue Claude              r  Resume Claude
  d  Deny diff                    t  Uraeda inline comments
  e  Uraeda field                 v  Uraeda verdict
  f  Focus Claude                 w  Uraeda waiting on me
  g  Uraeda commit
