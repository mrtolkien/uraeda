# Image fixtures

Inputs for the image encoder's tests, `crates/core/tests/images.rs`. Each file is named after what
it holds. They were made once, with Python's Pillow 12, ImageMagick 7 (libwebp 1.6.0), and git, by
scripts kept out of the repository; this file says enough to make them again.

| File            | What it holds                                                                                                                                                                                                                                               | How it was made                                                                                                                                                                       |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `desktop.png`   | A 1440×900 app screenshot                                                                                                                                                                                                                                   | `git show f30e3f7^:specs/2026-10-13-chat-in-the-web-ui/screenshots/chat-new-desktop-light.png`                                                                                        |
| `phone.png`     | A 402×874 app screenshot                                                                                                                                                                                                                                    | `git show f30e3f7^:specs/2026-10-13-chat-in-the-web-ui/screenshots/chat-new-phone-dark.png`                                                                                           |
| `photo.jpg`     | A 3000×2000 JPEG, quality 85: a blue gradient, a red 400×400 square in the stored top-left corner, and a yellow disc. EXIF: Make `UraedaPhone`, Model `UraedaCam 3000`, Orientation 6, and a GPS position (48°51′24″ N, 2°21′3″ E). XMP: the same model. | Pillow: `Image.new`, `ImageDraw` lines, rectangle, and ellipse; an `Image.Exif` with tags 0x010F, 0x0110, 0x0112, and the GPS IFD 0x8825; saved with `quality=85, exif=..., xmp=...` |
| `still.gif`     | A 64×48 single-frame GIF                                                                                                                                                                                                                                    | Pillow: `Image.new("P", (64, 48), 3).save(...)`                                                                                                                                       |
| `animated.gif`  | A 64×48 GIF of 3 frames, red, green, and blue, 200 ms each, looping                                                                                                                                                                                        | Pillow: `save(..., save_all=True, append_images=[...], duration=200, loop=0)`                                                                                                         |
| `lossy.webp`    | `phone.png` as lossy WebP, a `VP8 ` chunk                                                                                                                                                                                                                   | `magick phone.png -quality 80 lossy.webp`                                                                                                                                             |
| `lossless.webp` | `phone.png` as lossless WebP, a `VP8L` chunk                                                                                                                                                                                                                | `magick phone.png -define webp:lossless=true lossless.webp`                                                                                                                           |
| `drawing.svg`   | A 64×48 SVG of a red rectangle                                                                                                                                                                                                                              | Written by hand                                                                                                                                                                       |
| `page.png`      | An HTML page with a script, named `.png`                                                                                                                                                                                                                    | Written by hand                                                                                                                                                                       |
| `truncated.png` | The first 200 bytes of `desktop.png`: a valid signature and header, cut in its pixel data                                                                                                                                                                   | `head -c 200 desktop.png > truncated.png`                                                                                                                                             |
| `bomb.png`      | A 69-byte PNG whose header declares 20000×20000 RGB pixels, with one tiny `IDAT`                                                                                                                                                                           | Python: the PNG signature, an `IHDR` chunk (20000, 20000, depth 8, colour type 2) with its CRC, an `IDAT` of 64 zero bytes compressed with zlib, and `IEND`                         |

The screenshot corpus of SC-001 is not here: its ignored test reads the 94 screenshots from git
history, from the commits that finished their features (`f30e3f7^` and `3446a08^`).
